# Teenage Engineering EP-133 K.O. II — Cheat Sheet

*128 MB sampler and composer, successor to the PO-33 K.O!. 999 sample slots, 4 groups × 12 pads, 96 PPQN sequencer, 6 send FX + 12 Punch-In FX 2.0.*

## Top Panel Layout

| Section | Controls |
|---|---|
| **Display** | Custom segmented display (66 icons), step position, parameter values |
| **Mode** | SOUND, MAIN (home), TEMPO (BPM/ time sig) |
| **Function** | FX, SAMPLE, KEYS (chromatic), TIMING (note interval / swing) |
| **Transport** | RECORD, PLAY, ERASE |
| **Navigation** | SHIFT, − / +, KNOB X, KNOB Y, FADER |
| **Pads** | 12 velocity- & pressure-sensitive pads (also numpad 0–9, dot, enter) |
| **Groups** | GROUP A–D (pattern select, undo, copy, paste) |
| **Top jacks** | LINE IN (3.5 mm stereo), LINE OUT (3.5 mm stereo), SYNC IN/OUT, MIDI IN/OUT (TRS Type A), USB-C, power switch, volume knob |

## Project / Scene / Group / Pattern Structure

| Concept | Details |
|---|---|
| **Projects** | 9 per device, 80,000 notes each |
| **Groups** | 4 per project (A–D), each with 12 pads |
| **Patterns** | 99 per group, 1–99 bars each |
| **Scenes** | 99 per project — snapshot of 1 pattern from each group |
| **Song positions** | 99 — chain scenes into a full arrangement (up to 9,801 bars) |

## Sampling Workflow

1. Press **[SAMPLE]** — all pads blink, ready to record.
2. Press **−** / **+** to select input source: MIC, IN (line mono/stereo), RSP (resample mono/stereo), L.IN (left), R.IN (right), USB (mono/stereo).
3. **KNOB X** = input level, **KNOB Y** = threshold (auto-trigger when exceeded).
4. Hold a **pad** to start recording; release to stop.
5. Press the pad to audition. Press **[SAMPLE]** again or **[MAIN]** to exit.

**Hands-free sampling**: Hold **SHIFT** + press a pad to latch — K.O. II holds it for you. Press **PLAY** to record the pattern length. Press **[SAMPLE]** to stop.

**Resample**: Set source to RSP, latch a pad on an empty group, play to bounce your beat into a single sample.

**Chop (SHIFT + SAMPLE)**: Auto-chop (intelligent or equal-length division) or live chop (tap pads to set slice points). Refine start/end with **KNOB X** / **KNOB Y**.

Level (default) · Pan · FX Send · Pitch · Attack · Release · Filter Cutoff · Filter Resonance

| Effect | KNOB X | KNOB Y |
|---|---|---|
| **Delay** | Length (time) | Feedback (repeats) |
| **Reverb** | Length (room size) | Color (filter dark/bright) |

| **Chorus** | Modulation (rate) | Feedback (prominence) |

## Quick Tips

- Default sound categories: 1–99 kicks, 100–199 snares, 200–299 hats, 300–399 percussion, 400–499 bass, 500–599 melodic.
- **Commit often** (SHIFT + MAIN) — it duplicates the scene so you can evolve the arrangement without losing your place.
- Use **SHIFT + FADER** to reset the virtual fader and undo automation.
- Hold **SHIFT** while turning knobs or moving the fader for fine-grained adjustments.
- Set a pad's sample to `000` in Sound mode to create an empty MIDI-only pad that doesn't use a voice.
- **Sidechain**: SHIFT + FX → press + to access note-triggered sidechain. Select source sound, destination groups, length (KNOB X), and shape (KNOB Y).
- **Live input FX**: plug into LINE IN, press MAIN, turn up KNOB Y (FX send level) to process external audio through the selected effect.
- USB audio (class compliant) — use KO2 as an audio interface to your phone or computer.

### MIDI Sequencing External Gear

1. Press **SHIFT + SOUND** → page to MIDI settings.
2. **KNOB X** = MIDI channel (1–16), **KNOB Y** = root note.
3. Set a pad's sample to `000` in Sound mode for silent MIDI-only triggers.
4. Record as usual — notes are sent out on the assigned channel.

USB-C is class-compliant MIDI. TRS jack is Type A (ring = tip, sleeve = ground).
